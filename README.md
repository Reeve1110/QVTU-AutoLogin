# 泉州职业技术大学（泉大）校园网自动登录 · QVTU-AutoLogin

连上校园网（WiFi 名称以 `QVTU` 开头）就**自动完成认证**，
不用再手动开浏览器输账号密码。程序常驻系统托盘后台，**外网一断自动重登**，全程静默。
**单次登录约 7–12 秒。**

---

## 使用方法

1. **直接下载发行版 `AutoLogin.exe`** —— 点本页「克隆/下载」或直接点仓库里的 `AutoLogin.exe` 下载即可
   （它就是完整程序，**无需解压、无需安装**）。
2. **放到一个无人在意的角落** —— 把 `AutoLogin.exe` 挪到随便哪个不碍事的地方就行
   （例如 `D:\Tools\QVTU-AutoLogin\`）。别放桌面、别随手删掉。
3. **双击运行** —— 双击 `AutoLogin.exe`。
4. **简单设置一下** —— 首次运行会弹出窗口，填校园网的**账号、密码**，点「保存」。
   想要开机自启，就到「设置 → 开机自启」勾一下「开机自启」（会弹一次 UAC 授权框，点「是」即可；
   **默认是不启用的**，需要时再勾）。
5. **点一下右上角的 ✕（叉叉）** —— 窗口关掉即可，程序会自动缩进右下角托盘，
   在后台自动登录、断线重登，之后完全不用管。

> ⏳ 登录约需 **7–12 秒**（要拉起浏览器完成认证），请耐心等待，**不要重复双击**。
