# 泉州职业技术大学（泉大）校园网自动登录 · QVTU-AutoLogin

> **标签**：泉州职业技术大学 · 泉大 · QVTU · 校园网自动登录 · 自动认证 · WiFi 自动连接 · 开机自启 · 断网自动重登

连上校园网（WiFi 名称以 `QVTU` 开头，即**泉州职业技术大学**的校园网）就**自动完成认证**，
不用再手动开浏览器输账号密码。程序常驻系统托盘后台，**外网一断自动重登**，全程静默。
**平均登录时间约 5 秒。**

---

## 使用方法

1. **下载 ZIP** —— 点本页右上角「克隆/下载」→「下载 ZIP」。
2. **解压** —— 把下载的 ZIP 解压出来，得到一个文件夹（`QVTU-AutoLogin`）。
3. **放到一个无人在意的角落** —— 整个文件夹挪到随便哪个不碍事的地方就行
   （例如 `D:\Tools\QVTU-AutoLogin`）。别放桌面、别随手删掉；路径尽量不要带中文和空格。
4. **双击运行** —— 进文件夹，双击里面的 **`AutoLogin.exe`**。
5. **简单设置一下** —— 首次运行会弹出窗口，填校园网的**账号、密码**，点「保存」。
   想要开机自启，就勾一下「设置 → 开机自启 → 开机自启」（会弹一次 UAC 授权框，点「是」即可）。
6. **点一下右上角的 ✕（叉叉）** —— 窗口关掉即可，程序会自动缩进右下角托盘，
   在后台自动登录、断线重登，之后完全不用管。

> ⏳ 首次登录约需 **5 秒**（要拉起浏览器完成认证），请耐心等待，**不要重复双击**。

## 说明

- 专为**泉州职业技术大学（QVTU / 泉大）**校园网设计：识别以 `QVTU` 开头的校园 WiFi 并自动登录。
- 开机自动启动、断网自动重登、常驻托盘，全程后台静默运行，不弹黑窗。
- **v26.10.3 更新**：登录明显提速（定位表单从 5~9 秒降到约 0.3 秒、平均登录约 5 秒）；修复登录「假成功」导致久等的 bug；
  修复并加固 Chrome 登录（浏览器不可用时自动回退 Edge）；「开机自启」简化为**一个勾选框**——
  勾选后自动获取管理员权限，同时写好**任务计划程序**与**启动文件夹**两处，登录后立即后台启动；
  设置页新增「清除设置」（清理系统残留）与「恢复默认」。
- 账号密码只保存在本机 `config.json`，**不会上传、不外发**。
- 运行需要电脑已装 **Chrome 或 Edge** 浏览器（登录靠它完成认证；两个都没装会自动尝试内置内核）。
- 想改设置：再次双击 `AutoLogin.exe` 打开界面；想退出：右下角托盘图标右键 → 退出程序。
