# 泉州职业技术大学（泉大）校园网自动登录 · QVTU-AutoLogin

> **标签**：泉州职业技术大学 · 泉大 · QVTU · 校园网自动登录 · 自动认证 · WiFi 自动连接 · 开机自启 · 断网自动重登

连上校园网（WiFi 名称以 `QVTU` 开头，即**泉州职业技术大学**的校园网）就**自动完成认证**，
不用再手动开浏览器输账号密码。程序常驻系统托盘后台，**外网一断自动重登**，全程静默。
**单次登录约 7–12 秒。**

---

## 使用方法

1. **直接下载发行版 `AutoLogin.exe`** —— 点本页「克隆/下载」或直接点仓库里的 `AutoLogin.exe` 下载即可
   （它就是完整程序，**无需解压、无需安装**）。
2. **放到一个无人在意的角落** —— 把 `AutoLogin.exe` 挪到随便哪个不碍事的地方就行
   （例如 `D:\Tools\QVTU-AutoLogin\`）。别放桌面、别随手删掉。
3. **双击运行** —— 双击 `AutoLogin.exe`。
4. **简单设置一下** —— 首次运行会弹出窗口，填校园网的**账号、密码**，点「保存」。
   想要开机自启，就到「设置 → 开机自启」勾一下「开机自启」（会弹一次 UAC 授权框，点「是」即可；
   **默认是不启用的**，需要时再勾）。
5. **点一下右上角的 ✕（叉叉）** —— 窗口关掉即可，程序会自动缩进右下角托盘，
   在后台自动登录、断线重登，之后完全不用管。

> ⏳ 首次登录约需 **7–12 秒**（要拉起浏览器完成认证），请耐心等待，**不要重复双击**。

## 数据与日志放在哪

程序**不会**在 exe 旁边乱放文件。配置与日志统一放在你的**「文档」文件夹**下：

```
我的文档\AutoLogin\
├─ config.json      ← 你的设置与账号密码（只在本机，明文）
└─ logs\
   ├─ autologin.log ← 运行日志
   └─ diag.json     ← 自检报告（运行 --diag 时生成）
```

- **换电脑 / 挪动 exe 位置都不影响**：只要「文档\AutoLogin」还在，配置就还在。
- 日志**只保留最近 24 小时**，超期内容会自动清理，不会越积越多。

  「文档\AutoLogin」，升级时会自动把旧配置迁移过来；③ 日志**只保留 24 小时**；④ 细节修复。

  修复并加固 Chrome 登录（浏览器不可用时自动回退 Edge）；「开机自启」简化为**一个勾选框**——
  勾选后自动获取管理员权限，同时写好**任务计划程序**与**启动文件夹**两处，登录后立即后台启动；
  设置页新增「清除设置」（清理系统残留）与「恢复默认」。

- 想改设置：再次双击 `AutoLogin.exe` 打开界面；想退出：右下角托盘图标右键 → 退出程序。
